# Emergency Playbook

This guide helps you handle urgent situations even if no developer or volunteer is available.

---

## If All Else Fails

While less than ideal, AI models like ChatGPT, Claude, or Gemini can provide emergency fixes if prompted correctly,
including how to properly commit changes using version control, how to fix visual continuity errors, and update environments properly.

Remember that this is an absolute last ditch effort, which should not occur unless there is an emergency and no developer is available.

---

## Wrong Content Was Published

1. Log into the CMS
2. Go to the page or post
3. Click **Edit**
4. Correct the issue or click **Move to Trash**

Changes take effect immediately after updating.

---

## Uploaded Image or Video Is Breaking the Page

1. Edit the post
2. Remove the media
3. Update the post
4. Re-upload properly sized media later

---

## A Page Looks Broken

Do not attempt to fix layout.

- Remove any recently added content
- Save the post
- Contact a developer

---

## A Form Is Not Working

Forms are not controlled by the CMS.

Contact a developer.

---

## Checkout or Donations Not Working

This is handled by the API server.

Contact a developer immediately.
