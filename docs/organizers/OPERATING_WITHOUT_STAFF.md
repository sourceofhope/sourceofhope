# Operating the Website Without Staff or Volunteers

As a non-profit, there may be times when no volunteers or content creators are available.

You can still keep the website updated yourself by focusing only on these tasks:

- Updating event information
- Posting news and updates
- Replacing outdated images
- Correcting outdated text
- Publishing announcements

All of this can be done from the CMS without technical knowledge.

---

## Minimum Monthly Maintenance

At least once per month:

- Check homepage for outdated events
- Check program pages for outdated information
- Ensure contact information is correct
- Ensure featured images are appropriate

This keeps the website current and trustworthy.
