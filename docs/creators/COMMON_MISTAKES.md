# Common Mistakes and How to Fix Them

---

## Image Looks Too Large or Cropped

Cause: Image dimensions are incorrect.

Fix: Resize image to recommended dimensions and re-upload.

--

## Page or Content Loads Slowly

Cause: Image is incorrectly optimized

Fix: Optimize the image by lowering the resolution and using an efficient file format

---

## Page Looks Broken

Cause: Content pasted from Word/Google Docs.

Fix: Paste content into a plain text editor first, then into CMS.

---

## Video Not Showing

Cause: Incorrect embed method.

Fix: Paste only the YouTube/Vimeo URL on its own line.

---

## Wrong Page Updated

Always double-check the page title before editing.
