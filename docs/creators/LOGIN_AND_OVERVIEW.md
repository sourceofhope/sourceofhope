# CMS Login and Overview

This guide is for digital content creators. You do not need access to the codebase.

The website's editable content lives in **Sanity Studio**, our content management system (CMS). All of your work happens there.

---

## What You Are Responsible For

You can safely:

- Add, edit, and publish team members and team groups
- Add and update featured events and recurring events
- Post publications (news, articles, press links) and newsletters
- Add and update store products, including their prices
- Turn store checkout options (Stripe, PayPal) on or off
- Upload images and write their alt text

You should never attempt to:

- Change navigation menus
- Change page layouts or design
- Change page wording that is not in the Studio (most page text is part of the website code)
- Modify forms, checkout, or donation behavior
- Edit anything outside the Studio

If you need those changes, contact a developer. See `/docs/organizers/WHAT_NEEDS_DEVELOPER.md`.

---

## Getting Access

1. Ask the website administrator to invite you to the Sanity project. You will receive an email invitation.
2. Accept the invitation and create (or sign in to) your Sanity account.
3. Ask the administrator for the **Studio link**. It is a web address that usually ends in `.sanity.studio`.

Bookmark the Studio link. You only need a web browser.

Developers can also run the Studio on their own computer; see `/docs/recipes/guidelines/RUN_LOCALLY.md`.

---

## Logging In

1. Open the Studio link.
2. Sign in with the same method you used when accepting the invitation (for example Google, GitHub, or email and password).
3. You will land on the Studio's content list.

---

## What You Will See

The left sidebar lists every type of content the website uses:

- **Team Member** — people shown on the Team page
- **Team Group** — the groups team members belong to (for example "Executive Board")
- **Banner Event** — a site banner setting (not currently shown on the website)
- **Featured Event** — major events on the Events page
- **Recurring Event** — repeating programs on the Events page
- **Product** — items in the online store
- **Publication** — news, articles, and press links
- **Newsletter** — links to newsletter issues
- **Checkout Provider** — the express checkout buttons in the store

What each field means and where it appears on the website is described in `/docs/creators/CONTENT_TYPES_REFERENCE.md`.

How to create, edit, publish, and remove content is described in `/docs/creators/CREATE_EDIT_DELETE_CONTENT.md`.
