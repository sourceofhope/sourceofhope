# Creating, Editing, and Deleting Content

This is the core of your work.

---

## Creating a new post

For this example we'll create a new team member

1. Go to **Team Members --> Add New Team Member**
2. Enter the page title: name of the individual
3. Add content using the editor, filling in the provided form with their information
4. Set a featured image, the head shot of the team member
5. Click **Publish**

Importantly, anything outside of the meta form will not appear on the website, as the frontend only pulls structured data directly from the form, not the published page.

## The page will automatically appear on the website in the correct layout when you visit thesourceofhope.org/about/team or this team member's page available at thesourceofhope.org/about/team/<member_name>

## Editing an Existing Page

Using the same team member example, we'll edit a post with new information.

1. Go to **Team Members**
2. Search for the page by title
3. Click **Edit**
4. Make your changes, filling out the form with updated information
5. Click **Update**

Changes appear immediately on the site after updating.

---

## Creating a Post (Blog, News, Article)

The logic behind the above example is the same for all other post types that appear on the website:

1. Go to the specific post type: blog, event, member, etc
2. Add new post of this type
3. Add title, fill out the form with the correct content
4. Add a featured image (if applicable)
5. Click to **Publish**

---

## Deleting Content

1. Open the page or post
2. Click **Move to Trash**

Avoid permanently deleting unless instructed.
