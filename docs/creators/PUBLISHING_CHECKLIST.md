# Publishing Checklist

Remember, content published to the CMS is **immediately** served to visitors, so it's important that it is up-to-date, on-theme, appropriate, and helps spread hope.

Before clicking Publish or Update, confirm:

- Title is correct
- Featured image is set
- Images are properly sized
- Links work
- No spelling errors
- Content matches brand tone
- Correct category (for posts)

This prevents most common issues.
